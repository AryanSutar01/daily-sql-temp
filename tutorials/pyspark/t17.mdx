## How Built-in Functions Become JVM Bytecode

`pyspark.sql.functions` contains 300+ built-in functions, but from Spark's perspective they are not Python functions at all — they are **expression tree nodes** that Catalyst understands and compiles into optimized JVM bytecode. This is a fundamental difference from Python UDFs.

### The Expression Tree Model

When you write `F.upper(col("name"))`, you are constructing a **Catalyst expression object** — a tree node of type `Upper(AttributeReference("name"))`. When `F.round(col("amount") * 1.18, 2)` is written, it builds:

```
Round(
  Multiply(
    AttributeReference("amount"),
    Literal(1.18, DoubleType)
  ),
  Literal(2, IntegerType)
)
```

This expression tree is what Catalyst optimizes. It can:
- Apply **constant folding**: `Multiply(col, Literal(1.0))` → `col` (multiplying by 1 is a no-op)
- Apply **null propagation**: if `amount` is nullable, wrap in null check automatically
- Apply **type coercion**: auto-cast IntegerType to DoubleType where needed

### Tungsten Whole-Stage Codegen

After optimization, Tungsten compiles the entire expression tree into a **single JVM method**:

```java
// What Tungsten generates for: F.round(col("amount") * 1.18, 2)
// (simplified conceptual bytecode)
void processRow(UnsafeRow inputRow, UnsafeRow outputRow) {
    boolean amount_isNull = inputRow.isNullAt(2);
    if (amount_isNull) {
        outputRow.setNullAt(0);
    } else {
        double amount = inputRow.getDouble(2);
        double result = Math.round(amount * 1.18 * 100.0) / 100.0;
        outputRow.setDouble(0, result);
    }
}
```

This runs at near-native JVM speed with:
- Zero Python process involvement
- No row serialization/deserialization
- No object allocation per row (operates directly on `UnsafeRow` binary format)

### Python UDF Comparison

When you write `@udf def my_func(x): return x * 1.18`:

```
Per partition execution:
  JVM serializes each row to Python pickle bytes     ← CPU overhead
  Sends bytes over Unix domain socket to Python worker
  Python worker deserializes, calls my_func()
  Python worker serializes result back to pickle
  JVM receives and deserializes result               ← CPU overhead
  
Repeat for every single row in every partition
```

The serialization cost alone is typically **5–10x** the actual computation cost. For simple operations like `col * 1.18`, always use `F.col("amount") * 1.18` — never a UDF.

## Overview

`pyspark.sql.functions` (commonly imported as `F`) contains 300+ built-in functions that run natively on the JVM - no Python serialization overhead, unlike UDFs.

```python
from pyspark.sql import SparkSession
import pyspark.sql.functions as F
from pyspark.sql.functions import col, lit

spark = SparkSession.builder.appName("FunctionsDemo").getOrCreate()

# Best practice: import the whole module as F, use F.function_name()
# This avoids conflicts with Python builtins (sum, max, min, etc.)
```

## Math Functions

```python
df = spark.createDataFrame([(1, -4.7, 16.0, 3.14)], ["id", "a", "b", "c"])

df.select(
    F.abs(col("a")).alias("abs"),           # absolute value: 4.7
    F.ceil(col("a")).alias("ceil"),         # ceiling: -4
    F.floor(col("a")).alias("floor"),       # floor: -5
    F.round(col("c"), 1).alias("round"),    # round to 1 decimal: 3.1
    F.bround(col("c"), 1).alias("bround"),  # banker's round
    F.sqrt(col("b")).alias("sqrt"),         # square root: 4.0
    F.pow(col("b"), 2).alias("pow"),        # power: 256.0
    F.log(col("b")).alias("log"),           # natural log
    F.log10(col("b")).alias("log10"),       # log base 10: 1.2
    F.exp(col("c")).alias("exp"),           # e^x
    F.greatest(col("a"), col("b")).alias("greatest"),  # max of columns
    F.least(col("a"), col("b")).alias("least"),        # min of columns
    F.sign(col("a")).alias("sign"),         # -1, 0, or 1
    F.rand(seed=42).alias("rand"),          # random [0, 1)
    F.randn(seed=42).alias("randn"),        # random normal
).show()
```

## String Functions

```python
df = spark.createDataFrame([
    (1, "  hello world  ", "john.doe@email.com", "2024-01-15"),
], ["id", "text", "email", "date_str"])

df.select(
    # Case
    F.upper(col("text")).alias("upper"),
    F.lower(col("text")).alias("lower"),
    F.initcap(col("text")).alias("initcap"),   # Title Case

    # Trim whitespace
    F.trim(col("text")).alias("trim"),
    F.ltrim(col("text")).alias("ltrim"),
    F.rtrim(col("text")).alias("rtrim"),

    # Length and padding
    F.length(col("text")).alias("length"),
    F.lpad(col("date_str"), 12, "*").alias("lpad"),
    F.rpad(col("date_str"), 12, "*").alias("rpad"),

    # Substring and position
    F.substring(col("text"), 3, 5).alias("substr"),     # pos 3, length 5
    F.instr(col("text"), "world").alias("instr"),        # position of "world"

    # Split and concat
    F.split(col("email"), "@").alias("email_parts"),     # returns array
    F.concat(col("text"), lit("!")).alias("concat"),
    F.concat_ws("-", col("text"), col("date_str")).alias("concat_ws"),

    # Regex
    F.regexp_extract(col("email"), r"(\w+)@", 1).alias("username"),
    F.regexp_replace(col("text"), r"\s+", "_").alias("underscored"),
    F.regexp_like(col("email"), r".*@.*\..*").alias("valid_email"),  # Spark 3.5+

    # Checks
    F.contains(col("text"), "world"),   # deprecated - use col.contains()
).show(truncate=False)
```

## Date and Timestamp Functions

```python
from pyspark.sql.functions import (
    current_date, current_timestamp, to_date, to_timestamp,
    date_add, date_sub, datediff, months_between, add_months,
    year, month, dayofmonth, dayofweek, dayofyear,
    hour, minute, second,
    date_format, trunc, date_trunc
)

df = spark.createDataFrame([
    (1, "2024-01-15", "2024-03-22 14:30:00"),
], ["id", "date_str", "ts_str"])

df.select(
    # Parse strings to date/timestamp
    F.to_date(col("date_str"), "yyyy-MM-dd").alias("date"),
    F.to_timestamp(col("ts_str"), "yyyy-MM-dd HH:mm:ss").alias("ts"),

    # Current values
    F.current_date().alias("today"),
    F.current_timestamp().alias("now"),

    # Extract parts
    F.year(F.to_date(col("date_str"))).alias("year"),
    F.month(F.to_date(col("date_str"))).alias("month"),
    F.dayofmonth(F.to_date(col("date_str"))).alias("day"),
    F.dayofweek(F.to_date(col("date_str"))).alias("dow"),      # 1=Sun
    F.dayofyear(F.to_date(col("date_str"))).alias("doy"),
    F.quarter(F.to_date(col("date_str"))).alias("quarter"),
    F.weekofyear(F.to_date(col("date_str"))).alias("week"),

    # Arithmetic
    F.date_add(F.to_date(col("date_str")), 30).alias("plus_30_days"),
    F.date_sub(F.to_date(col("date_str")), 7).alias("minus_7_days"),
    F.datediff(F.current_date(), F.to_date(col("date_str"))).alias("days_since"),
    F.add_months(F.to_date(col("date_str")), 3).alias("plus_3_months"),
    F.months_between(F.current_date(), F.to_date(col("date_str"))).alias("months_since"),

    # Formatting
    F.date_format(F.to_date(col("date_str")), "dd/MM/yyyy").alias("formatted"),
    F.date_format(F.to_date(col("date_str")), "MMMM dd, yyyy").alias("long_format"),

    # Truncate to period
    F.trunc(F.to_date(col("date_str")), "month").alias("month_start"),
    F.trunc(F.to_date(col("date_str")), "year").alias("year_start"),
    F.date_trunc("hour", F.to_timestamp(col("ts_str"))).alias("hour_trunc"),
).show(truncate=False)
```

## Conditional Functions

```python
df = spark.createDataFrame([
    (1, "Alice", 95000, None),
    (2, "Bob",   72000, 5000),
    (3, "Carol", None,  None),
], ["id", "name", "salary", "bonus"])

df.select(
    # when / otherwise (CASE WHEN)
    F.when(col("salary") > 90000, "Senior")
     .when(col("salary") > 70000, "Mid")
     .otherwise("Junior").alias("level"),

    # coalesce - first non-null
    F.coalesce(col("bonus"), lit(0)).alias("bonus_safe"),
    F.coalesce(col("salary"), lit(50000)).alias("salary_safe"),

    # nullif - return null if two values are equal
    F.nullif(col("salary"), lit(72000)).alias("not_72k"),

    # ifnull / nvl
    F.ifnull(col("bonus"), lit(0)).alias("bonus_ifnull"),

    # nvl2 - like ternary: if col is not null → val1, else → val2
    F.nvl2(col("bonus"), lit("has_bonus"), lit("no_bonus")).alias("bonus_status"),
).show()
```

## Aggregate Functions (used inside agg())

```python
df = spark.createDataFrame([
    ("A", 10), ("A", 20), ("B", 5), ("B", None),

df.groupBy("grp").agg(

    F.sum("val").alias("sum"),
    F.avg("val").alias("avg"),
    F.min("val").alias("min"),
    F.max("val").alias("max"),
    F.sum_distinct("val").alias("sum_distinct"),
    F.stddev("val").alias("stddev"),
    F.variance("val").alias("variance"),
    F.skewness("val").alias("skewness"),
```

## Best Practices

```python
# ✅ Always use built-in functions over Python UDFs
# Built-in: runs in JVM, no serialization overhead
df.withColumn("upper_name", F.upper(col("name")))   # fast

# ❌ Avoid when built-in exists
from pyspark.sql.functions import udf
upper_udf = udf(lambda x: x.upper() if x else None)
df.withColumn("upper_name", upper_udf(col("name"))) # slow - Python UDF

# ✅ Import as F to avoid shadowing Python builtins
import pyspark.sql.functions as F
df.groupBy("dept").agg(F.sum("salary"), F.max("salary"))  # not Python sum/max

# ❌ Direct import conflicts with Python builtins
from pyspark.sql.functions import sum, max  # shadows Python built-ins!
```

## Summary

- Import as `import pyspark.sql.functions as F` to avoid conflicts with Python builtins
- Built-in functions run in the JVM - always prefer them over Python UDFs
- **Math**: `abs`, `ceil`, `floor`, `round`, `sqrt`, `pow`, `log`, `greatest`, `least`
- **String**: `upper`, `lower`, `trim`, `length`, `substring`, `split`, `concat`, `regexp_*`
- **Date**: `to_date`, `to_timestamp`, `year`, `month`, `datediff`, `date_add`, `date_format`
- **Conditional**: `when/otherwise`, `coalesce`, `nullif`, `ifnull`
- **Array**: `size`, `explode`, `array_distinct`, `array_sort`, `collect_list`, `collect_set`
- **Aggregate**: `count`, `sum`, `avg`, `min`, `max`, `stddev`, `percentile_approx`
