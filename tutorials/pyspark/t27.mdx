## Array and Explode: Memory and Execution Implications

Array operations, `explode`, and `collect_list` look like simple transformations but have significant memory and performance implications in distributed execution.

### How explode() Multiplies Row Count and Partition Size

`explode(array_col)` transforms one row with an array of N elements into N separate rows — one per element. In a distributed context, this means:

```
Partition 0 before explode:
  Row 1: [user_id=1, tags=["spark", "python", "sql"]]   → 1 row, ~50 bytes
  Row 2: [user_id=2, tags=["hadoop", "hive"]]           → 1 row, ~40 bytes
  Total: 2 rows, ~90 bytes

Partition 0 after explode:
  Row 1: [user_id=1, tag="spark"]
  Row 2: [user_id=1, tag="python"]
  Row 3: [user_id=1, tag="sql"]
  Row 4: [user_id=2, tag="hadoop"]
  Row 5: [user_id=2, tag="hive"]
  Total: 5 rows, ~150 bytes
```

If arrays have average size 100, `explode()` creates 100× more rows. For a 10GB DataFrame, post-explode data may be **1TB**. This dramatically increases:
- Shuffle data volume in any subsequent `groupBy` or `join`
- Memory pressure on executors
- Number of output partitions needed

**Best practice**: Filter and select before explode — apply all predicates on the pre-explode data first.

### collect_list and the Data Skew / OOM Trap

`collect_list(col)` is the inverse of `explode` — it aggregates multiple rows into one array. But it creates a **data skew risk** in distributed execution:

```
groupBy("user_id").agg(collect_list("event"))

If user 1001 has 10M events across all partitions:
  After groupBy shuffle: all 10M events for user 1001 land on ONE executor
  collect_list accumulates all 10M events as a JVM ArrayList on that executor
  Each event ~100 bytes → 1GB list for ONE user
  → Executor OOM!
```

`collect_list` grows **unbounded** — Spark has no limit on how large the resulting array can be. For high-activity users/entities, this is a common source of executor OOM in production pipelines.

Mitigation strategies:
```python
# Option 1: Limit collection size
from pyspark.sql.functions import slice
df.groupBy("user_id") \
  .agg(collect_list("event").alias("events")) \
  .withColumn("events", slice("events", 1, 1000))  # keep max 1000

# Option 2: Pre-aggregate to reduce cardinality before collecting
df.groupBy("user_id", "event_type") \
  .agg(count("event").alias("event_count")) \
  .groupBy("user_id") \
  .agg(collect_list(struct("event_type", "event_count")))
```

### Variable-Length Memory Layout in Tungsten UnsafeRow

Arrays and strings are stored as **variable-length regions** in Tungsten's memory layout:

```
UnsafeRow for: [user_id=1, tags=["spark","python"]]

Fixed-width section (per column):
  user_id: 8 bytes (Long value = 1)
  tags:    8 bytes (offset pointer → variable-length region)

Variable-length section:
  [4 bytes: array length=2]
  [4 bytes: "spark" length=5][5 bytes: "spark"]
  [4 bytes: "python" length=6][6 bytes: "python"]

Total: 8 + 8 + 4 + 4+5 + 4+6 = 39 bytes (vs Python list: ~300+ bytes with overhead)
```

This compact binary layout is why Tungsten arrays are memory-efficient — but also why array element access requires offset arithmetic, making per-element random access slightly more expensive than fixed-width column access.

## Setup

```python
from pyspark.sql import SparkSession
from pyspark.sql.functions import (
    col, explode, explode_outer, posexplode,
    collect_list, collect_set,
    array, array_contains, array_distinct, array_union, array_intersect,
    array_except, array_sort, array_max, array_min, array_size, size,
    flatten, arrays_zip,
    map_keys, map_values, map_from_arrays, create_map, explode as map_explode
)

spark = SparkSession.builder.appName("ArrayMapDemo").getOrCreate()

orders = spark.createDataFrame([
    (1, "Alice", ["Laptop", "Mouse", "Keyboard"]),
    (2, "Bob",   ["Monitor"]),
    (3, "Carol", ["Laptop", "Headphones"]),
    (4, "Dave",  []),               # empty array
    (5, "Eve",   None),             # null array
], ["order_id", "customer", "items"])
```

## explode - Array to Rows

`explode()` turns each element of an array into its own row.

```python
orders.withColumn("item", explode(col("items"))).show()
# +--------+--------+----------+
# |order_id|customer|      item|
# +--------+--------+----------+
# |       1|   Alice|    Laptop|
# |       1|   Alice|     Mouse|
# |       1|   Alice|  Keyboard|
# |       2|     Bob|   Monitor|
# |       3|   Carol|    Laptop|
# |       3|   Carol|Headphones|
# +--------+--------+----------+
# Note: Dave (empty) and Eve (null) are DROPPED by explode()
```

## explode_outer - Keep Nulls and Empties

```python
orders.withColumn("item", explode_outer(col("items"))).show()
# +--------+--------+----------+
# |order_id|customer|      item|
# +--------+--------+----------+
# |       1|   Alice|    Laptop|
# |       1|   Alice|     Mouse|
# |       1|   Alice|  Keyboard|
# |       2|     Bob|   Monitor|
# |       3|   Carol|    Laptop|
# |       3|   Carol|Headphones|
# |       4|    Dave|      null|   ← empty array → one null row (kept)
# |       5|     Eve|      null|   ← null array → one null row (kept)
# +--------+--------+----------+
```

## posexplode - Array to Rows with Index

```python
from pyspark.sql.functions import posexplode, posexplode_outer

orders.withColumn("pos_item", posexplode(col("items"))) \
      .select("order_id", "customer",
              col("pos_item.pos").alias("position"),
              col("pos_item.col").alias("item")) \
      .show()
# +--------+--------+--------+----------+
# |order_id|customer|position|      item|
# +--------+--------+--------+----------+
# |       1|   Alice|       0|    Laptop|
# |       1|   Alice|       1|     Mouse|
# |       1|   Alice|       2|  Keyboard|
# |       2|     Bob|       0|   Monitor|
# ...

# Simpler posexplode syntax in Spark 3+
orders.select("order_id", "customer",
    posexplode("items").alias("position", "item")
).show()
```

## collect_list & collect_set - Rows to Array

The inverse of explode - aggregate rows back into arrays.

```python
sales = spark.createDataFrame([
    ("Alice", "Engineering", "Laptop"),
    ("Alice", "Engineering", "Mouse"),
    ("Bob",   "Marketing",   "Monitor"),
    ("Bob",   "Marketing",   "Headphones"),
    ("Bob",   "Marketing",   "Monitor"),   # duplicate
], ["employee", "dept", "product"])

# collect_list - preserves duplicates
sales.groupBy("employee").agg(
    collect_list("product").alias("all_products")
).show(truncate=False)
# +--------+-------------------------------+
# |employee|all_products                    |
# +--------+-------------------------------+
# |Alice   |[Laptop, Mouse]                |
# |Bob     |[Monitor, Headphones, Monitor] |  ← Monitor appears twice
# +--------+-------------------------------+

# collect_set - deduplicates
sales.groupBy("employee").agg(
    collect_set("product").alias("unique_products")
).show(truncate=False)
# +--------+-------------------------+
# |employee|unique_products          |
# +--------+-------------------------+
# |Alice   |[Laptop, Mouse]          |
# |Bob     |[Monitor, Headphones]    |  ← deduplicated
# +--------+-------------------------+
```

## Array Functions

```python
from pyspark.sql.functions import (
    size, array_contains, array_distinct, array_sort,
    array_max, array_min, array_union, array_intersect,
    array_except, flatten, slice, array_remove, array_position,
    element_at, arrays_zip, transform, filter as array_filter, aggregate
)

df = spark.createDataFrame([
    (1, [3, 1, 4, 1, 5, 9, 2, 6]),
    (2, [7, 8, 9]),
], ["id", "numbers"])

df.withColumn("count",     size(col("numbers"))) \
  .withColumn("max_val",   array_max(col("numbers"))) \
  .withColumn("min_val",   array_min(col("numbers"))) \
  .withColumn("sorted",    array_sort(col("numbers"))) \
  .withColumn("distinct",  array_distinct(col("numbers"))) \
  .withColumn("first3",    slice(col("numbers"), 1, 3)) \
  .withColumn("has_5",     array_contains(col("numbers"), 5)) \
  .show(truncate=False)

# Set operations on arrays
df2 = spark.createDataFrame([
    ([1, 2, 3], [2, 3, 4]),
], ["arr1", "arr2"])

df2.withColumn("union_arr",      array_union("arr1", "arr2")) \
   .withColumn("intersection",   array_intersect("arr1", "arr2")) \
   .withColumn("difference",     array_except("arr1", "arr2")) \
   .show()

# Remove element, find position
df.withColumn("no_ones",  array_remove(col("numbers"), 1)) \
  .withColumn("pos_of_5", array_position(col("numbers"), 5)) \  # 1-indexed
  .withColumn("element_at_3", element_at(col("numbers"), 3)) \  # 1-indexed
  .show()

# Flatten nested arrays
nested = spark.createDataFrame([([[1,2],[3,4],[5]],)], ["nested"])
nested.withColumn("flat", flatten(col("nested"))).show()
# flat: [1, 2, 3, 4, 5]
```

### Higher-Order Functions (Spark 2.4+)

```python
from pyspark.sql.functions import transform, filter, aggregate, forall, exists

df = spark.createDataFrame([(1, [1, 2, 3, 4, 5]),], ["id", "nums"])

# transform - apply function to each element (like map)
df.withColumn("doubled", transform(col("nums"), lambda x: x * 2)).show()
# doubled: [2, 4, 6, 8, 10]

# filter - keep elements matching predicate
df.withColumn("evens", array_filter(col("nums"), lambda x: x % 2 == 0)).show()
# evens: [2, 4]

# aggregate - reduce array to single value
df.withColumn("total", aggregate(col("nums"), lit(0), lambda acc, x: acc + x)).show()
# total: 15

# forall - True if all elements match
df.withColumn("all_positive", forall(col("nums"), lambda x: x > 0)).show()

# exists - True if any element matches
df.withColumn("has_even", exists(col("nums"), lambda x: x % 2 == 0)).show()
```

## Map Functions

```python
scores = spark.createDataFrame([
    (1, {"math": 95, "science": 88, "english": 76}),
    (2, {"math": 72, "english": 91}),
], ["user_id", "scores"])

# map_keys / map_values
scores.withColumn("subjects",    map_keys(col("scores"))) \
      .withColumn("score_vals",  map_values(col("scores"))) \
      .show(truncate=False)

# Access specific key
scores.withColumn("math_score", col("scores")["math"]).show()
scores.withColumn("math_score", element_at(col("scores"), "math")).show()

# Explode map into key-value rows
scores.select(
    "user_id",
    explode(col("scores")).alias("subject", "score")
).show()
# +-------+-------+-----+
# |user_id|subject|score|
# +-------+-------+-----+
# |      1|   math|   95|
# |      1|science|   88|
# |      1|english|   76|
# |      2|   math|   72|
# |      2|english|   91|
# +-------+-------+-----+

# Create map from two arrays
df_map = spark.createDataFrame([
    (["a", "b", "c"], [1, 2, 3]),
], ["keys", "values"])
df_map.withColumn("my_map", map_from_arrays(col("keys"), col("values"))).show()

# create_map from column values
from pyspark.sql.functions import create_map, lit
df.select(create_map(
    lit("name"), col("name"),
    lit("dept"), col("dept")
).alias("info_map")).show()
```

## arrays_zip - Combine Multiple Arrays

```python
df_zip = spark.createDataFrame([
    (["Laptop", "Mouse"], [50000, 800]),
], ["products", "prices"])

df_zip.withColumn("product_price",
    arrays_zip(col("products"), col("prices"))
).show(truncate=False)
# product_price: [{Laptop, 50000}, {Mouse, 800}]

# Explode the zipped array
df_zip.withColumn("zipped", arrays_zip(col("products"), col("prices"))) \
      .withColumn("item", explode("zipped")) \
      .select(
          col("item.products").alias("product"),
          col("item.prices").alias("price")
      ).show()
```

## Summary

- `explode()` - array/map → one row per element; drops null/empty
- `explode_outer()` - same but keeps null/empty arrays as a null row
- `posexplode()` - explode with element position index
- `collect_list()` - aggregate rows into array (keeps duplicates)
- `collect_set()` - aggregate rows into array (deduplicates)
- Array functions: `size`, `array_contains`, `array_sort`, `array_distinct`, `array_union`, `array_intersect`, `slice`, `flatten`
- Higher-order functions: `transform`, `filter`, `aggregate`, `forall`, `exists` - apply lambdas to array elements
- Map functions: `map_keys`, `map_values`, `element_at`, `explode` on maps
- `arrays_zip` - combine parallel arrays into array of structs
