## Variables

In Python, a variable is not a bucket that holds data (like in C or Java). Instead, it is better thought of as a **label** or a **name tag** that is attached to an object stored in memory. 

When you assign a value to a variable, Python creates the object in memory and then binds the variable name to that object. This process is called "name binding." This is why you don't need to declare a variable's type; the type lives with the object in memory, not the label you attach to it.

```python
name = "Alice"      # name is bound to the string object "Alice"
age = 30            # age is bound to the integer object 30

# Multiple assignment / unpacking
a, b = 1, 2
```

## Core Data Types

Python provides several built-in, fundamental data types. Everything in Python is an object, including these basic types.

1. **Integer (`int`):** Represents whole numbers. In Python 3, integers have arbitrary precision, meaning they can grow as large as your computer's memory allows without overflowing.
2. **Float (`float`):** Represents decimal numbers. Python uses 64-bit IEEE 754 double precision floats. This means they are accurate to about 15-17 decimal places but are subject to floating-point rounding errors (e.g., `0.1 + 0.2` is not exactly `0.3`).
3. **String (`str`):** A sequence of Unicode characters. Strings are **immutable**, meaning once created, they cannot be changed.
4. **Boolean (`bool`):** Represents truth values (`True` or `False`). Internally, booleans are actually a subclass of integers, where `True` is `1` and `False` is `0`.
5. **NoneType (`None`):** Represents the intentional absence of a value. It is a singleton object.

```python
age = 25              # int
pi = 3.14159          # float
name = "Alice"        # str
active = True         # bool
result = None         # NoneType
```

## type() and isinstance()

Because Python variables do not have fixed types, you often need to check what type of object a variable is currently bound to at runtime.

- `type(x)`: Returns the exact type (class) of the object.
- `isinstance(x, type)`: Returns a boolean indicating if an object is an instance of a specific class or any of its subclasses. This is the preferred method for type checking in Python because it handles inheritance correctly.

```python
x = 42
print(type(x))               # <class 'int'>
print(isinstance(x, int))    # True
```

## Type Conversion (Casting)

Type conversion is the process of converting a value from one data type to another. Python allows **explicit** conversion using built-in constructor functions. Unlike some languages, Python tries to avoid implicit conversion (coercion) to prevent unexpected behaviors, though it will implicitly convert an `int` to a `float` in mathematical operations.

When explicitly converting, Python will raise an error if the conversion doesn't make logical sense (e.g., converting the string "abc" into an integer).

```python
# Explicit conversion
str_num = "42"
actual_num = int(str_num)    # Converts string to integer
truncated = int(3.9)         # Converts float to int (truncates to 3)

# Failed conversion
# int("abc") raises a ValueError
```

## Truthy and Falsy Values

In Python, you don't need a strict boolean to evaluate a condition. Every object in Python has a boolean value inherently attached to it. When an object is used in an `if` statement or a boolean context, Python evaluates it as either **Truthy** or **Falsy**.

The rule of thumb is that **empty or zero values are Falsy**, and **everything else is Truthy**. This feature allows for very readable and concise code.

**Falsy values include:** `False`, `0`, `0.0`, `""` (empty string), `[]` (empty list), `{}` (empty dictionary), `None`.

```python
user_list = []

# Instead of checking: if len(user_list) > 0:
if user_list:
    print("List has users")
else:
    print("List is empty")  # This executes because [] is Falsy
```

## Dynamic Typing

Python is a **dynamically typed** language. This means types are checked and enforced at runtime, not at compile time. 

Furthermore, because variables are just labels bound to objects, the same variable name can be reassigned to bind to completely different types of objects throughout the execution of your program. While flexible, this requires discipline to avoid confusing bugs.

```python
x = 10           # x is bound to an int
x = "hello"      # x is now bound to a string (perfectly legal)
```

## Naming Conventions

Python relies heavily on community conventions to maintain readable code across different projects. The definitive guide for this is **PEP 8** (Python Enhancement Proposal 8).

- **Variables and Functions:** `snake_case` (lowercase words separated by underscores).
- **Constants:** `UPPER_SNAKE_CASE` (Python doesn't have true constants, so uppercase acts as a warning to other developers not to change the value).
- **Private Variables:** Prefixing a variable with a single underscore (e.g., `_cache`) is a convention to indicate it is meant for internal use only.

```python
user_name = "Alice"   # Standard variable
MAX_RETRIES = 3       # Constant
_internal_data = []   # Private/Internal variable
```

## Interview Questions

**Q: What are Python's built-in data types?**
Core primitive types are `int`, `float`, `str`, `bool`, and `NoneType`. (Python also includes built-in collections like lists, tuples, and dictionaries). Importantly, all values in Python are objects.

**Q: What is the difference between `int` and `float` in Python?**
`int` stores whole numbers with arbitrary precision, meaning they will not overflow regardless of size. `float` stores decimal numbers using the 64-bit IEEE 754 format, which is precise to about 15 significant digits but is susceptible to standard floating-point rounding errors.

**Q: Explain Truthy and Falsy values.**
In boolean contexts (like `if` statements), Python evaluates objects as True or False. Falsy values are generally "empty" or "zero" (e.g., `0`, `""`, `[]`, `None`, `False`). Almost all other objects evaluate to Truthy.

**Q: What does it mean that Python is dynamically typed?**
It means that variables do not have fixed types declared at compile time. A variable is simply a label for an object in memory, and its type is determined at runtime based on the object it is currently bound to. The same variable can be bound to an integer and later bound to a string.

## Summary

- **Variables:** Labels bound to objects in memory, not data containers.
- **Data Types:** `int` (unlimited precision), `float` (IEEE 754), `str` (immutable), `bool`, `None`.
- **Type Checking:** Prefer `isinstance()` over `type()` to properly account for inheritance.
- **Booleans:** Utilize "Truthy" and "Falsy" evaluation for concise conditional checks.
- **Dynamic Typing:** Variable types are resolved at runtime and can change dynamically.
- **Conventions:** Follow PEP 8 (e.g., `snake_case` for variables, `UPPER_CASE` for constants).
