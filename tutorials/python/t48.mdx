## What Are Regular Expressions?

Regular expressions (regex) are patterns for matching and extracting text. Python's `re` module provides full regex support.

```python
import re

text = "Contact us at support@example.com or sales@company.org"
emails = re.findall(r"[\w.+-]+@[\w-]+\.[a-z]{2,}", text)
print(emails)   # ['support@example.com', 'sales@company.org']
```

## Core Functions

```python
import re

text = "Hello, my phone is 98765-43210 and backup is 91234-56789"

# re.search() - find FIRST match anywhere in the string
match = re.search(r"\d{5}-\d{5}", text)
if match:
    print(match.group())   # 98765-43210
    print(match.start())   # 21 - start index
    print(match.end())     # 32 - end index
    print(match.span())    # (21, 32)

# re.match() - match only at the START of string
re.match(r"\d+", "123abc")   # match
re.match(r"\d+", "abc123")   # None - doesn't start with digits

# re.fullmatch() - entire string must match the pattern
re.fullmatch(r"\d+", "12345")    # match
re.fullmatch(r"\d+", "12345x")   # None

# re.findall() - all non-overlapping matches as a list of strings
phones = re.findall(r"\d{5}-\d{5}", text)
# ['98765-43210', '91234-56789']

# re.finditer() - returns iterator of match objects
for m in re.finditer(r"\d{5}-\d{5}", text):
    print(m.group(), m.start())

# re.sub() - replace matches
clean = re.sub(r"\d{5}-\d{5}", "[REDACTED]", text)
# "Hello, my phone is [REDACTED] and backup is [REDACTED]"

# re.split() - split on pattern
parts = re.split(r"[,\s]+", "one, two,   three  four")
# ['one', 'two', 'three', 'four']
```

## Pattern Syntax

```python
# Character classes
r"\d"      # any digit [0-9]
r"\D"      # any non-digit
r"\w"      # word character [a-zA-Z0-9_]
r"\W"      # non-word character
r"\s"      # whitespace (space, tab, newline)
r"\S"      # non-whitespace
r"."       # any character except newline

# Custom character classes
r"[aeiou]"      # any vowel
r"[a-z]"        # lowercase letter
r"[A-Za-z]"     # any letter
r"[^0-9]"       # anything NOT a digit (^ inside [] = negate)

# Quantifiers
r"a*"      # 0 or more a's
r"a+"      # 1 or more a's
r"a?"      # 0 or 1 a (optional)
r"a{3}"    # exactly 3 a's
r"a{2,5}"  # 2 to 5 a's
r"a{2,}"   # 2 or more a's

# Anchors
r"^hello"  # must start with "hello"
r"world$"  # must end with "world"
r"\bhello\b"  # word boundary - matches "hello" but not "helloworld"

# Groups
r"(abc)"     # capturing group
r"(?:abc)"   # non-capturing group
r"(?P<name>abc)"  # named capturing group
```

## Groups and Capturing

```python
import re

# Capturing groups - access with group(1), group(2)...
date = "2024-03-15"
m = re.match(r"(\d{4})-(\d{2})-(\d{2})", date)
if m:
    print(m.group(0))   # "2024-03-15" - entire match
    print(m.group(1))   # "2024" - first group
    print(m.group(2))   # "03"
    print(m.group(3))   # "15"
    print(m.groups())   # ('2024', '03', '15')

# Named groups - cleaner for complex patterns
m = re.match(r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})", date)
print(m.group("year"))   # "2024"
print(m.groupdict())     # {'year': '2024', 'month': '03', 'day': '15'}
```

## Flags

```python
import re

text = "Hello WORLD\nhello world"

# re.IGNORECASE (re.I) - case insensitive
re.findall(r"hello", text, re.IGNORECASE)   # ['Hello', 'hello']

# re.MULTILINE (re.M) - ^ and $ match start/end of each line
re.findall(r"^hello", text, re.MULTILINE | re.IGNORECASE)
# ['Hello', 'hello']

# re.DOTALL (re.S) - . matches newline too
re.findall(r"WORLD.hello", text, re.DOTALL | re.IGNORECASE)
# ['WORLD\nhello']

# Combine flags with |
re.search(r"hello", text, re.I | re.M)
```

## Compiling Patterns - Better Performance

```python
import re

# Compile once, use many times - faster for repeated use
pattern = re.compile(r"(\d{4})-(\d{2})-(\d{2})")

dates = ["2024-03-15", "invalid", "2023-12-31"]
for d in dates:
    m = pattern.match(d)
    if m:
        print(m.groups())
```

## Common Real-World Patterns

```python
import re

# Email validation
email_pattern = re.compile(r"^[\w.+-]+@[\w-]+\.[a-z]{2,}$", re.IGNORECASE)
email_pattern.match("user@example.com")   # match
email_pattern.match("not-an-email")       # None

# Indian phone number
phone = re.compile(r"^(\+91|0)?[6-9]\d{9}$")
phone.match("9876543210")    # match
phone.match("+919876543210") # match

# URL extraction
urls = re.findall(r"https?://[^\s]+", text)

# Extract numbers (int or float)
re.findall(r"-?\d+\.?\d*", "prices: 29.99, -5, 100.0")
# ['29.99', '-5', '100.0']

# Remove HTML tags
clean = re.sub(r"<[^>]+>", "", "<p>Hello <b>World</b></p>")
# "Hello World"

# Validate date format YYYY-MM-DD
date_re = re.compile(r"^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$")
date_re.match("2024-03-15")   # match
date_re.match("2024-13-01")   # None - invalid month

# Split on multiple delimiters
re.split(r"[,;|\s]+", "a,b; c|d  e")
# ['a', 'b', 'c', 'd', 'e']
```

## re.sub with a Function

```python
import re

# Replace each match using a function
def double_number(match):
    return str(int(match.group()) * 2)

result = re.sub(r"\d+", double_number, "I have 3 cats and 10 dogs")
# "I have 6 cats and 20 dogs"

# Censoring words
words_to_censor = {"bad", "awful", "terrible"}
def censor(match):
    word = match.group()
    return word[0] + "*" * (len(word) - 1)

text = "That was bad and awful"
pattern = re.compile(r"\b(" + "|".join(words_to_censor) + r")\b", re.I)
print(pattern.sub(censor, text))
# "That was b** and a****"
```

## Interview Questions

**Q: What is the difference between `re.match()` and `re.search()`?**
`re.match()` only checks for a match at the beginning of the string. `re.search()` scans the entire string and returns the first match anywhere. For most use cases, `re.search()` is what you want.

**Q: What is a raw string (`r"..."`) and why use it for regex?**
A raw string treats backslashes as literal characters - `r"\n"` is two characters (`\` and `n`), not a newline. Since regex patterns use many backslashes (`\d`, `\w`, `\s`), raw strings prevent Python from interpreting them first. Always use raw strings for regex patterns.

**Q: What is the difference between a capturing group `()` and a non-capturing group `(?:)`?**
Both group parts of a pattern. A capturing group `()` stores the matched text, accessible via `group(n)` or `groups()`. A non-capturing group `(?:)` groups without storing - useful for applying quantifiers to a group without capturing.

**Q: When should you use `re.compile()`?**
When the same pattern is used multiple times. `re.compile()` compiles the pattern once into a regex object, which is faster than recompiling on every call. For patterns used only once, `re.search(pattern, text)` is equally fine.

## Summary

- `re.search(pattern, text)` - first match anywhere; `re.match()` - only at start
- `re.findall()` - list of all matches; `re.finditer()` - iterator of match objects
- `re.sub(pattern, replacement, text)` - replace matches; replacement can be a function
- `re.split(pattern, text)` - split on pattern
- Key patterns: `\d` digits, `\w` word chars, `\s` whitespace, `.` any char, `^` start, `$` end
- Quantifiers: `*` zero+, `+` one+, `?` optional, `{n,m}` range
- `()` capturing group; `(?:)` non-capturing; `(?P<name>)` named group
- Always use raw strings `r"..."` for regex patterns
- `re.compile(pattern)` - compile once, reuse many times for better performance
- Flags: `re.I` case-insensitive, `re.M` multiline, `re.S` dot matches newline
