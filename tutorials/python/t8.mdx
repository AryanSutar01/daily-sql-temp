## *args - Variable Positional Arguments

`*args` collects any number of positional arguments into a **tuple**.

```python
def add(*args):
    print(type(args))   # <class 'tuple'>
    return sum(args)

add(1, 2)          # 3
add(1, 2, 3, 4)    # 10
add()              # 0

def greet(*names):
    for name in names:
        print(f"Hello, {name}!")

greet("Alice", "Bob", "Carol")
```

## **kwargs - Variable Keyword Arguments

`**kwargs` collects any number of keyword arguments into a **dict**.

```python
def display(**kwargs):
    print(type(kwargs))   # <class 'dict'>
    for key, value in kwargs.items():
        print(f"{key} = {value}")

display(name="Alice", age=30, city="Mumbai")
# name = Alice
# age = 30
# city = Mumbai
```

## Combining Both

```python
def func(*args, **kwargs):
    print("Positional:", args)
    print("Keyword:", kwargs)

func(1, 2, 3, name="Alice", age=30)
# Positional: (1, 2, 3)
# Keyword: {'name': 'Alice', 'age': 30}
```

## Order of Parameters

```python
# Correct order: regular → *args → keyword-only → **kwargs
def example(a, b, *args, keyword_only, **kwargs):
    print(a, b, args, keyword_only, kwargs)

example(1, 2, 3, 4, keyword_only="must", extra="value")
# 1 2 (3, 4) must {'extra': 'value'}
```

## Unpacking with * and **

Use `*` and `**` when **calling** a function to unpack a list/tuple or dict:

```python
def add(a, b, c):
    return a + b + c

args = [1, 2, 3]
add(*args)   # same as add(1, 2, 3)

kwargs = {"a": 1, "b": 2, "c": 3}
add(**kwargs)   # same as add(a=1, b=2, c=3)

# Combine
def func(a, b, c, d):
    return a + b + c + d

func(*[1, 2], **{"c": 3, "d": 4})   # 10
```

## Practical Uses

```python
# Passing arguments through to another function
def log_and_call(func, *args, **kwargs):
    print(f"Calling {func.__name__} with {args}, {kwargs}")
    return func(*args, **kwargs)

def multiply(x, y):
    return x * y

log_and_call(multiply, 3, 4)   # Calling multiply with (3, 4), {}; returns 12

# Flexible constructors
class Config:
    def __init__(self, **kwargs):
        for key, value in kwargs.items():
            setattr(self, key, value)

cfg = Config(host="localhost", port=5432, debug=True)
print(cfg.host)   # localhost
```

## Interview Questions

**Q: What is the difference between `*args` and `**kwargs`?**
`*args` collects extra positional arguments into a tuple. `**kwargs` collects extra keyword arguments into a dict. Use `*args` when you want to accept any number of positional values; use `**kwargs` for any number of named values.

**Q: What is the difference between `*args` in a function definition vs calling a function with `*list`?**
In a definition, `*args` collects arguments into a tuple. When calling a function, `*list` unpacks a list/tuple into separate positional arguments - the inverse operation.

**Q: What is the correct order of parameters in a function signature?**
`def f(positional, *args, keyword_only, **kwargs)` - regular positional params first, then `*args`, then keyword-only params (after `*`), then `**kwargs`.

## Summary

- `*args` - collects extra positional args into a **tuple**; iterate with `for x in args`
- `**kwargs` - collects extra keyword args into a **dict**; iterate with `kwargs.items()`
- Order: `regular, *args, keyword_only, **kwargs`
- Unpack when calling: `f(*list)` → positional args; `f(**dict)` → keyword args
- Common use: pass-through functions, flexible APIs, decorators
