## Defining and Calling Functions

In Python, a function is not just a block of code; it is a **First-Class Object**. When you use the `def` keyword, you are actually creating a function object in memory and binding it to a variable name (the function's name). 

Functions encapsulate logic, define variable scope, and promote code reusability. 

```python
# 'greet' is now a label bound to a function object
def greet(name):
    print(f"Hello, {name}!")

greet("Alice") 
```

## Parameters vs. Arguments

In computer science, there is a strict distinction between parameters and arguments:
- **Parameters** are the variables defined in the function signature (e.g., `def add(a, b):`).
- **Arguments** are the actual values passed into the function during execution (e.g., `add(3, 4)`).

Python supports both positional arguments (resolved by their order) and keyword arguments (resolved by their parameter name).

```python
def describe_pet(name, animal="dog"):
    return f"{name} is a {animal}"

# Positional argument
describe_pet("Max")

# Keyword argument (order doesn't matter)
describe_pet(animal="cat", name="Whiskers")
```

## The Return Statement

The `return` statement immediately terminates the function's execution frame and sends a value back to the caller. 

Fundamentally, **every function in Python returns a value**. If you do not explicitly write a `return` statement, Python implicitly injects `return None` at the end of the function.

Python also allows returning multiple values. Under the hood, Python achieves this by packing the return values into a single **Tuple**. 

```python
def min_max(numbers):
    # This actually returns a single tuple: (min, max)
    return min(numbers), max(numbers)   

# Tuple unpacking allows us to assign them to separate variables
low, high = min_max([3, 1, 4, 1, 5, 9])
```

## First-Class Functions and Higher-Order Functions

Because functions are objects, Python supports **Functional Programming** paradigms. 

Functions can be:
1. Assigned to variables.
2. Passed as arguments to other functions.
3. Returned from other functions.

A function that accepts another function as an argument or returns a function is called a **Higher-Order Function**.

```python
def square(x):
    return x ** 2

# Passing a function object (square) as an argument
def apply_to_all(func, values):
    return [func(x) for x in values]

apply_to_all(square, [1, 2, 3])  # Returns [1, 4, 9]
```

## Lambda Functions (Anonymous Functions)

A **lambda** function is an anonymous, inline function. It is restricted to a single expression (no statements or loops allowed). 

The architectural use case for a lambda is to provide a quick, throwaway function to a higher-order function (like `map()` or `sorted()`) without polluting the local namespace with a `def` statement.

```python
names = ["Charlie", "Alice", "Bob"]

# Using a lambda to sort the list by the length of the string
sorted_names = sorted(names, key=lambda name: len(name))
```

## Function Scope (LEGB Rule)

When you reference a variable inside a function, Python looks for it using the **LEGB rule**:
1. **L**ocal: Variables defined inside the current function.
2. **E**nclosing: Variables defined in nested parent functions.
3. **G**lobal: Variables defined at the top level of the module.
4. **B**uilt-in: Python's pre-assigned names (like `print`, `len`).

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        x = "local"
        print(x)  # Resolves to "local"
    inner()
```

## Interview Questions

**Q: What is a first-class function?**
A first-class function is a function that is treated as a standard data object. It can be assigned to variables, passed as an argument to other functions, and returned from functions. This concept is the architectural foundation of Python decorators.

**Q: Does every function in Python return a value?**
Yes. If a function does not have a `return` statement, or has a bare `return` with no value, it implicitly returns the `None` object.

**Q: How does Python return multiple values?**
Python doesn't actually return multiple separate values; it packs the values into a single Tuple object and returns that Tuple. The caller can then use tuple unpacking to distribute the values into multiple variables.

**Q: What is the difference between a parameter and an argument?**
A parameter is the variable defined in the function signature. An argument is the actual data value passed to that parameter when the function is invoked.

## Summary

- **Functions as Objects:** `def` binds a function object to a variable name.
- **Parameters vs Arguments:** Parameters are definitions; arguments are the actual runtime values.
- **Return Values:** All functions return a value; implicitly returning `None` if omitted. Multiple returns are packed into a tuple.
- **Higher-Order Functions:** Functions can be passed into and returned by other functions.
- **Lambdas:** Anonymous, single-expression functions used for short, inline operations.
- **Scope:** Variables are resolved using the LEGB rule (Local, Enclosing, Global, Built-in).
